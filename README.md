# Анализ продаж интернет-магазина

## О проекте

Проект посвящён анализу данных о продажах интернет-магазина за 12 месяцев.
Цель анализа — изучить динамику продаж, определить наиболее результативные месяцы и города, проанализировать популярность товаров, средний чек и активность покупателей в течение дня.

## Инструменты

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Что было сделано в проекта:

* объединены данные о продажах за несколько месяцев;
* проведена первичная проверка и очистка данных;
* обработаны пропущенные значения и дубликаты;
* преобразованы даты и созданы дополнительные признаки;
* рассчитана выручка по каждому заказу;
* проанализирована динамика выручки по месяцам;
* исследована выручка по городам;
* определено количество проданных единиц каждого товара;
* рассчитан средний чек;
* проанализирована динамика среднего чека по месяцам;
* исследовано распределение заказов по часам;
* определены товары с наибольшей выручкой.

## Основные результаты

В результате анализа были получены данные о:

* динамике продаж в течение года;
* месяцах с максимальной выручкой;
* распределении выручки между городами;
* наиболее продаваемых товарах;
* товарах с наибольшей выручкой;
* среднем чеке;
* времени наибольшей активности покупателей.

Конкретные значения и визуализации представлены в Jupyter Notebook.
