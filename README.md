#  Анализ продаж интернет-магазина

Проект посвящён разведочному анализу данных (EDA) о продажах интернет-магазина электроники за 12 месяцев (2019 год). 
Цель — изучить динамику продаж, определить ключевые бизнес-метрики, выявить сезонность и паттерны покупательского поведения.

## Инструменты
- **Язык:** Python
- **Библиотеки:** Pandas, NumPy, Matplotlib
- **Среда:** Jupyter Notebook
- **БД:** SQL (примеры запросов см. в `queries.sql`)

## Основные результаты (Key Insights)
В ходе анализа было обработано **185 687 транзакций**. Получены следующие бизнес-инсайты:
- **Общая выручка:** ~$34.4 млн при среднем чеке **$193.15**.
- **Сезонность:** Пик продаж приходится на декабрь (выручка **$4.6 млн**, что составляет ~13% от годовой).
- **Активность:** Наибольшее количество заказов совершается в **19:00** (12 377 заказов), а также в обеденное время (11:00–12:00).
- **География:** Выявлены города-лидеры по объему выручки для таргетирования рекламы.
- **Товары:** Определен топ-5 товаров, генерирующих максимальную выручку.

## Что было сделано (Data Pipeline)
1. **Сбор и объединение:** Загружено и склеено 12 CSV-файлов (по месяцам) в единый датасет.
2. **Очистка (Data Cleaning):** Обработано более 1 100 некорректных записей (удалены пропуски `NaN` и дубликаты).
3. **Feature Engineering:** Преобразованы типы данных (datetime, numeric), созданы новые признаки: `Month`, `Hour`, `City`, `Sales`.
4. **Анализ и визуализация:** Рассчитаны агрегированные метрики (KPI) и построены графики динамики с помощью Matplotlib.
